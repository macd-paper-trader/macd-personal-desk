MACD Personal Desk - GitHub Pages 上傳包

這個資料夾只包含可直接發布的免費個人版網站檔案。

步驟：
1. 建立 GitHub 公開 repository：macd-personal-desk
2. 在 repository 按 Add file → Upload files
3. 把本資料夾內的 index.html、assets 資料夾、market-snapshot-template.csv 及這個說明檔一起上傳。
4. Commit changes。
5. 到 Settings → Pages，選 Deploy from a branch，Branch 選 main，Folder 選 /(root)，再按 Save。
6. 等候數分鐘後，GitHub 會顯示你的免費網址。

注意：不要上傳這個 ZIP 檔本身；請先解壓，然後上傳解壓後資料夾內的檔案。

使用前請先下載「市場快照 CSV」範本，按網站內的「匯入 CSV」導入資料後才按「更新」。
